# ひよりルート「固め濃いめ多めな後輩と、硬め普通少なめな俺」

- 主人公: ユウキ（26）。ブログ名は「かさたた」。川崎在住、転職したてのWebエンジニア。交際経験ゼロ
- ヒロイン: 天宮ひより（24）。新卒2年目のしごできエンジニア。社歴は先輩、年齢は後輩。一人称「うち」、主人公は「センパイ」

表記: （ ）は主人公の心の声、【選択肢】のあとの ▶ は選んだときの反応。反応のあとは本筋に合流する。『』はチャットやLINEの文面、または記事からの引用。

## 構成

1周は「共通パート（2シーン）→ 山札から引いたイベント（5シーン）→ 分岐したルート（2シーン）→ エンディング」。

- 山札のイベントは、14枚から毎回5枚をランダムに引き、原作の記事の月の順に並べる。どれが出るかわからないので、イベント同士で話をつなげない（共通パートの出来事だけを前提にしてよい）
- ルートは、選択肢で動いた3つの気持ち（ときめき・信頼・ノリ）で重みを付けたくじで決まる。ルートの軸の値で GOOD / NORMAL が分かれる
- 選択肢の反応は人が書いたものをそのまま出し、LLM は選んだ結果の気持ちの変化だけを判定する
- 実装は `GyaruGame/Resources/Content/script_<シーンID>.json`。この文書のほうが描写が細かいところもある
