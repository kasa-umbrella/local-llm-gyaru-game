# 定時後ローカルLLM 〜ブログのネタは、だいたい恋になる〜

ブログ「kasa-blog」の全記事（25本）を原作に、無理やりラブコメに仕立てたシナリオ設計書。
ゲームでは各シーンを `script_<シーンID>.json` のビート（地の文／セリフ／選択肢）として実装し、
LLM は選択肢への反応と言い回しの変化だけを担当する。

## 主人公

**ユウキ（26）** ／ ブログでのハンドルネームは「かさたた」、非公式の呼び名は「かっさー」

- 川崎駅徒歩圏内に住む Web エンジニア。転職して3か月目。府中から引っ越してきた
- 文学部卒（学士・文学）。交際経験ゼロ。好きなラノベは『向かいのしごでき後輩は、ベランダで甘えたい』
- 「ブログのネタセンサー」が発火すると、だいたいろくでもない行動に出る
- 家系は「硬め普通少なめチャーシュー抜き」。博多風龍は「バリカタ」。HHKB（無刻印 → 一部刻印あり）使い
- 暗いところが怖い。照明のリモコンは猫になって旅に出た

> 物語のエンジン: 主人公がブログのネタ探しで無茶をする → その現場にヒロインがいる → ラブコメになる → それをまたブログに書く → ヒロインに読まれる

### 年齢と設定の変更点（実装時に heroines.json へ反映）

- ひより: 26歳 → **24歳**。中途の主人公より社歴が長いので、業務では先輩風を吹かせつつ「センパイ」呼び
- 澪: 30歳 → **26歳**。大学の同期に変更
- るか: 31歳 → **29歳**。「三十路目前」で焦る幼なじみ。「行き遅れ」いじりは本人の自虐としてだけ使う

## ひよりルート　「固め濃いめ多めな後輩と、硬め普通少なめな俺」

### 第1章「転職しました」　オフィス（`office_building_evening`）
原作: 転職しました／HHKB／無刻印、やめました／ちょっと変えてみました

- 転職初日、隣の席のひよりが「業務的にはうちが先輩っすけど、年齢的にはセンパイなんで、センパイって呼ぶっす」と宣言
- 主人公の無刻印 HHKB を見て「それ、数字打てます？」。ワンタイムパスワードの入力で3回連続で失敗する主人公
- ひよりのデスクには刻印ありの HHKB。チームが全員 HHKB という謎の文化
- **選択肢**: 「無刻印はロマンだから」（teasing）／「……刻印、便利そうだな」（honest）／「ブラインドタッチの練習中なんだ」（cool）
- 反応の意図の例: 正直に負けを認めると「素直なセンパイ、ポイント高いっす」と笑う
- 締め: 「デスクの上と CI/CD は整っているほどいいっすよ」と言いながら、主人公の CI を勝手に直していく

### 第2章①「いっかくや」　川崎駅前・夜（`station_square_night`）
原作: いっかくや／いっかくや2／コメントにレスするシリーズ①

- 定時の19時を過ぎて20時30分、致死量の白米を求めて川崎へ。いっかくやの前でひよりと鉢合わせる
- ひよりは「固め濃いめ多め」派。主人公の「硬め普通少なめチャーシュー抜き」を「浅瀬で遊んでますね」と言い放つ
- **正体バレ**: その言い回し、ブログに来た謎のコメントと完全一致。「……あのコメント、お前か」
- **選択肢**: 「油で誤魔化してないか？」（teasing、家系の本質論をぶつける）／「読んでくれてたんだ」（honest）／「業務時間中に書くな」（cool）
- 白米食べ放題は終わっていた。ひよりがこっそり自分のライスを半分くれる

### 第2章②「飲み会を抜け出して」　オフィス街・夜（`office_building_night`）

- 大人数の飲み会。主人公はトイレに行くふりをして、博多風龍へ抜け出そうとする
- 店の外で「センパイ、どこ行くんすか」と、ひよりに捕まる
- 二人でバリカタ、替え玉2回。「面接の帰りに博多風龍に寄ると受かる」ジンクスの話から、九州出張で深夜3時まで泣きながらコードを直した話へ
- **選択肢**: 「替え玉、もう一回いく？」（romantic）／「前の会社、最後に認めてもらえたんだ」（honest）／「飲み会、戻らなくていいの？」（cool）
- 何事もなかったかのように二人で飲み会に戻る。誰も気づいていない

### 第3章①「ビリヤニと、日曜日」　ラ・チッタ・デッラ・夕方（`station_square_evening`）
